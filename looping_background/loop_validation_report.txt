BETA 泡泡循環背景 — 循環驗證報告
=====================================
產生日期：2026-10-18
Blender 4.2.23 LTS（Cycles，CPU，4 核心，無 GPU）

1. 參考圖與動畫內容
-------------------
參考圖：source/reference_v3.jpg（2000 x 1116，長寬比 1.792）
動畫內容（依用戶要求，只有這一項）：
  - 只有右上角與左下角兩群泡泡（細胞）會動。
  - BETA 字標、線框球、虹膜線條、左上淡弧線、右下線團：完全靜止，與原圖一致。
  - 無任何其他效果（無光效、無霧、無粒子、無鏡頭移動、無 bloom、無淡入淡出、無字幕或浮水印）。

泡泡的動作：
  - 每個泡泡各自脹縮（半徑的 8–14%，x 自動安全係數 0.9），每 5.33 秒一次，
    相位以波浪形式在泡泡群中傳遞，加上隨機偏移。
  - 每個泡泡繞小圓軌道游移（半徑的 6–12%），每 8 秒一圈，相位隨機。
  - 膜的細微蠕動（約 1 px 參考圖像素），每 16 秒一輪。
  - 兩群泡泡整體極緩慢漂浮（位移 <= 0.5% 畫面高度，旋轉 <= 0.45 度），每 16 秒一圈。
  - 偵測到 177 個泡泡（包括未封閉的大泡泡）；其餘小泡泡隨鄰近泡泡一起移動。

2. 循環規格
-----------
  幀率：30 fps
  長度：16.000 秒
  唯一幀數：480（渲染第 0–479 幀；第 480 幀 = 第 0 幀，不重複輸出）
  解析度：3840 x 2160（4K UHD）

3. 無縫循環的做法
-----------------
  - 所有動畫都是循環相位 p = frame / 480 的函數，只用 sin/cos(2*pi*k*p)，
    k 為整數（1、2、3）。因此第 480 幀在數學上等於第 0 幀，速度與加速度也相同。
  - 數百個泡泡各自不同相位的運動，寫成 A*sin(th+phi) = sin(th)*A*cos(phi) + cos(th)*A*sin(phi)，
    預先烘焙成 4 張向量場紋理，著色器每幀以 sin/cos 線性組合，嚴格週期。
  - 膜蠕動用兩張獨立噪聲場 N1、N2，以 cos(th)*N1 + sin(th)*N2 組合（週期、方差恆定）。
  - 無模擬快取、無隨機數、無粒子生滅。
  - 泡泡群整體漂浮用 Blender driver（皆為 simple expression，重開 .blend 不需啟用 Python 自動執行）。
  - Cycles 取樣種子固定（不隨幀變化），避免靜止區域閃爍。
  - 防摺疊保護：位移場 x -> x - d(x) 在 96 組相位組合下的最小雅可比行列式 = 0.308 (> 0)，
    膜不會翻折或撕裂。

5. 渲染與編碼設定
-----------------
  渲染：Cycles CPU，8 spp，無降噪（純發光場景無噪點；降噪會抹掉細線），
        Blackman-Harris 1.0 px，固定種子，無動態模糊，色彩管理 Standard
        （精確重現原圖色調），輸出 16-bit PNG。約 20 秒/幀。
  紋理：原圖以 Lanczos-3 重取樣至 3871x2160（以高度對齊 4K），線性插值約 1:1 取樣。
  looping_background_4k.mp4：H.264 High@L5.2，CRF 10，yuv420p，GOP 30（1 秒），
        關閉 fast-pskip / dct-decimate，I/P/B 等質量，BT.709，約 23 Mbps，46 MB。
  looping_background_master.mov：ProRes 422 HQ，10-bit 4:2:2，1.28 GB。
  looping_background_4k_hapq.mov：HAP Q（4 chunks），給 Resolume / VDMX / TouchDesigner 等 VJ 軟件，1.34 GB。
  preview.mp4：960x540，H.264 CRF 14。

6. 限制與取捨
-------------
  - 參考圖只有 2000x1116；放大到 4K（約 1.94 倍）不會產生原圖沒有的細節，畫面清晰度受原圖限制。
  - 參考圖長寬比 1.792 略寬於 16:9，左右各裁掉約 0.4%（4K 下每邊約 15 px），無拉伸。
  - H.264 的固有限制：每秒一次的關鍵幀處有極輕微的畫質轉換（平均約 0.05 / 255 的額外差異），
    循環接縫正好落在關鍵幀上，所以接縫與其他關鍵幀轉場同一水平，但不是零。
    ProRes 與 HAP Q 為幀內編碼，無此問題；正式演出建議使用 HAP Q。
  - 泡泡運動是對原圖的 2D 變形，不是 3D 物理模擬；未封閉的大泡泡以圓形範圍近似其中心與半徑。
  - 泡泡群漂浮時，貼著畫面邊緣的泡泡可能露出最多約 10–15 px（4K）的鏡像延伸內容。
  - ProRes 與 HAP Q 檔案超過 GitHub 100 MB 上限，未提交到倉庫，只存在於雲端容器中。

7. 重現方法
-----------
  blender -b -P create_animation.py -- --render          # 建場景 + 渲染 4K 幀（預設即最終設定：3840x2160、8 spp）
  ./encode.sh final                                      # 編碼 4K H.264 / ProRes / HAP Q
  blender -b looping_background.blend -P validate_loop.py -- out.json --render-dir dir
  python3 check_video_seam.py looping_background_4k.mp4
